# BBC Academy — Front-end

A self-contained, one-page English academy website built with plain HTML, CSS, and JavaScript.

## Open it

Extract the ZIP and open `index.html` in a browser. No React, package installation, database, or backend is required.

## Included

- Arabic-first, bilingual page with a mobile navigation menu
- Six course paths with instructor portraits and expandable course details
- “Explore all courses” control
- Academy story, instructor profiles, student quote examples, and enrollment form
- Local hero and teacher images

The enrollment form only validates the fields and shows a demo confirmation; it does not send or save information. Teacher names, portraits, course details, and student quotes are illustrative content and should be replaced with approved academy information before public use.
